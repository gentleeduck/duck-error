# Support

Thanks for using **duck-error**.

If you need help:

- Check our docs: [gentleduck.org/duck-error](https://gentleduck.org/duck-error)
- Join discussions: [GitHub Discussions](https://github.com/gentleeduck/duck-error/discussions)
- Found a bug? [Open a Bug Report](https://github.com/gentleeduck/duck-error/issues/new?template=bug_report.md)
- Have an idea? [Submit a Feature Request](https://github.com/gentleeduck/duck-error/issues/new?template=feature_request.md)

Please **don't use GitHub Issues for support requests** - use Discussions or Chat instead.
